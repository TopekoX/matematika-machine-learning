# Level 0 — Fondasi Matematika

Level ini membangun dasar yang dibutuhkan sebelum belajar aljabar, fungsi, aljabar linear, kalkulus, probabilitas, dan akhirnya Machine Learning. Tidak ada prasyarat selain kemauan belajar.

!!! warning "Status materi"
    Seluruh 8 part Level 0 sudah tersedia dan bisa dibaca dari tabel di bawah.

## Tujuan Level 0

Setelah menyelesaikan Level 0, kamu mampu:

- mengenali dan membedakan jenis-jenis bilangan;
- menghitung dengan benar memakai operasi dasar, urutan operasi, pecahan, desimal, dan persentase;
- memakai rasio, proporsi, pangkat, akar, nilai absolut, dan notasi ilmiah;
- membaca variabel, ekspresi, persamaan sederhana, dan notasi sigma;
- memahami bagaimana konsep-konsep ini muncul di Machine Learning.
